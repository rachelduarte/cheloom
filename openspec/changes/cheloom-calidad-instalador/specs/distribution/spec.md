# Spec — distribution (nuevo dominio)

## Requirements
- R1. Debe existir un instalador `CHELOOM Setup x.y.z.exe` que instale por usuario, sin pedir permisos de administrador.
- R2. El instalador MUST crear accesos directos en el Escritorio y en el menú Inicio, con el ícono de marca.
- R3. El acceso del menú Inicio MUST tener el atajo **Ctrl+Alt+C**.
- R4. Abrir CHELOOM ya abierta MUST traer el panel al frente, no abrir otra instancia.
- R5. CHELOOM MUST poder desinstalarse desde Configuración → Aplicaciones.

## UC-7 Abrir CHELOOM con el teclado
1. La creadora pulsa **Ctrl+Alt+C** desde cualquier app.
2. Se abre CHELOOM (o pasa al frente si ya estaba abierta).
